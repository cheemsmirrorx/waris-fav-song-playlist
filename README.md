## 🎶 About The Project

**Waris' Fav Songs** is a personal web-based music playlist created as one of my first projects during my **BCA 1st semester**.

The idea was simple:

> **Take the songs I love and turn them into a clean, interactive web experience.** 🎧

Instead of building another basic static webpage, I wanted to experiment with the fundamentals of **frontend development**, including layout design, styling, JavaScript interactions, audio controls, and responsive UI.

---

## ✨ Features

| Feature                     | Description                                            |
| --------------------------- | ------------------------------------------------------ |
| 🎵 **Music Playlist**       | Browse through my personally selected songs            |
| ▶️ **Audio Playback**       | Play and control songs directly from the website       |
| 🎨 **Custom UI**            | Designed with a modern music-player inspired interface |
| 📱 **Responsive Design**    | Designed to work across different screen sizes         |
| ⚡ **Lightweight**           | Built using vanilla web technologies                   |
| 🖼️ **Album Artwork**       | Visual artwork for the playlist experience             |
| 🔊 **Interactive Controls** | JavaScript-powered music interactions                  |
| 🌐 **Live Deployment**      | Hosted online with Vercel                              |
